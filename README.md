# Edit_Master
Edit Master é um editor de vídeo gratuito e de código aberto, desenvolvido com Tauri, React e Rust. O projeto busca oferecer edição acessível, interface moderna, bom desempenho em PCs modestos e ferramentas integradas de mídia e IA, com foco no Windows. Em desenvolvimento, com evolução aberta à comunidade. Aberto a contribuições da comunidade.
